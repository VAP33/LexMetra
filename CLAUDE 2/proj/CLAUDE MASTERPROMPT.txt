1. FIRST PRINCIPLE
============================================================

The central architecture of this project is:

AI/CV extracts evidence.
Deterministic legal rules evaluate applicable requirements.
Human inspectors resolve uncertainty.

NEVER reverse this relationship.

AI must NOT independently invent legal requirements.
An LLM/VLM must NOT decide that a package is legally compliant.
RAG must NOT directly produce the final compliance verdict.
Similarity detection must NOT be treated as product identity.
Tampering detection must NOT claim counterfeit/authenticity unless independently verified.
“Not observed” must NOT automatically mean “missing”.
An image alone must NOT be treated as legally sufficient evidence when the evidence is inadequate.

The system must explicitly support:

PASS
FAIL
UNCERTAIN
EXEMPT

The final legal decision must always be traceable to:
- applicable requirement
- rule ID
- rule version
- evidence
- extracted fact
- reason
- confidence
- review state

→ UNCERTAIN

→ request another capture

→ request recapture

→ REVIEW REQUIRED
